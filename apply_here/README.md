# Apply Here

Apply one modifier without leaving Edit Mode.

Part of **Nano Tools**, small everyday add-ons by **m3shtry**. Blender 4.2 or newer.

## Install

Edit > Preferences > Get Extensions, arrow menu at the top right > **Install from Disk**, pick the zip.
Or drag the zip into the Blender window.
To remove it: Get Extensions, find the add-on, its arrow menu > **Uninstall**.

## Where

3D View, Sidebar (**N**), tab **Nano Tools**, panel **Apply Here**.

## How it works

The panel lists the modifiers of the active mesh. Press **Apply** next to the one you need.
The modifier is applied, you stay in Edit Mode, the rest of the stack stays as it is.

A modifier lower in the stack is applied to the base mesh, as if the ones above it weren't there.
A modifier hidden in the viewport is applied too.

## Modifier list on a hotkey

- **Modifier List** opens the same list as a menu. Right-click it > **Add to Quick Favorites** and it's on **Q**.
- Or tick **Q in Edit Mode opens the modifier list** in the add-on preferences. It's off by default: the add-on takes no hotkeys.
